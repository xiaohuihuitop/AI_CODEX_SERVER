# 手机端多设备管理

## 目标

让手机 App 保存并切换多台 Windows Codex 电脑。用户可以从首页顶部直接切换已有设备，在设置页新增、编辑、删除和测试设备连接；切换后只显示并控制目标设备的数据。

## 背景与确认事实

- 当前手机端只保存一组 `{serverUrl, token}`，首页通过该配置建立 HTTP 请求与 WebSocket 连接。
- 云端 Relay 已按 Token 隔离 Agent、线程缓存、实时客户端和控制请求。一台电脑使用一个独立 Token 时，MVP 无需修改服务器协议。
- 首页已有生命周期令牌、请求取消、定时器停止和 Socket 关闭机制，可以作为设备切换事务的基础。
- 用户确认首页顶部“Codex 手机端”区域适合作为设备切换入口。
- 用户确认设备下拉弹窗只负责切换；添加、编辑、删除和测试连接全部位于设置页。
- 用户确认存在未发送草稿时禁止切换设备，并提示“请先发送或清空草稿”。

## 需求

### R1 设备数据模型

- 手机本地保存设备列表和当前设备 ID。
- 每台设备包含稳定内部 ID、设备名称、服务器地址和 Token。
- 设备名称用于展示，内部 ID 用于状态和选择隔离；名称不作为路由键。
- 每台设备独立保存最后选中的项目和对话。
- 首次加载新版时，将现有单设备配置和选择无损迁移为第一台设备；迁移完成后只使用新数据模型。

### R2 首页设备切换

- 首页原生导航栏标题区域显示当前设备名称和下拉提示，不再固定显示“Codex 手机端”。
- 点击标题打开设备选择弹窗，弹窗仅展示已保存设备、当前设备和各设备最近一次连接状态。
- 弹窗不提供添加、编辑或删除入口。
- 选择当前设备不触发重连。
- 存在未发送草稿时禁止切换，并提示“请先发送或清空草稿”。
- 切换成功后关闭弹窗，并加载目标设备最后选中的项目和对话。

### R3 原子连接切换

- 切换设备前先废弃当前生命周期，停止轮询和重连定时器、关闭旧 WebSocket、取消全部旧 HTTP 请求。
- 清空旧设备的线程、消息、运行状态、待确认发送和提示状态，禁止旧异步结果写入新设备页面。
- 切换当前设备配置与设备级选择后，再建立新设备连接并加载状态、列表、历史和实时订阅。
- 切换失败时停留在目标设备的明确错误状态，不自动切回旧设备，也不尝试其他 Token。
- 新旧设备的数据、实时事件和控制请求不得串线。

### R4 设置页设备管理

- 设置页展示设备列表，并支持新增、编辑、删除和测试连接。
- 新增和编辑时设备名称、服务器地址、Token 均必填。
- 服务器地址保存时去除尾部斜杠，Token 去除首尾空白。
- 删除设备前需要二次确认。
- 首页存在草稿时，删除当前设备必须拒绝并使用同一提示语；删除非当前设备不受草稿影响。
- 删除当前设备后切换到列表第一台设备；没有设备时进入未配置状态。
- 设置页管理动作只操作本地配置；测试连接使用表单中的目标设备配置，不切换首页当前设备。

### R5 状态和兼容性

- 设备弹窗显示的在线状态来自该设备最近一次实际健康检查结果，并标注为最近状态，不伪装成持续实时状态。
- 当前设备继续使用实时 WebSocket 和定时校验更新首页状态。
- 旧单设备用户升级后无需重新输入服务器地址和 Token。
- 不修改服务器 Token 路由契约，不允许一个 Token 同时代表多台电脑。

## 验收标准

- [ ] 旧版已有配置升级后自动生成第一台设备，服务器地址、Token、项目和对话选择均保留。
- [ ] 设置页可以新增两台设备、编辑设备名称和连接配置、逐台测试连接。
- [ ] 首页顶部显示当前设备名称，点击后弹出仅含已有设备的切换列表。
- [ ] 在两台不同 Token 的在线电脑间连续切换 5 次，每次只显示目标设备的线程和历史，旧事件不会回写。
- [ ] 每台设备切换回来后恢复各自最后选择的项目和对话。
- [ ] 输入框含草稿时，点击另一设备不切换并提示“请先发送或清空草稿”。
- [ ] 设备切换期间旧 HTTP 请求被取消、旧 WebSocket 被关闭、旧轮询被停止。
- [ ] 删除非当前设备成功；删除当前设备需确认并切到第一台剩余设备；删除最后一台后首页显示未配置状态。
- [ ] 手机向设备 A 发送消息后只在 A 的官方 Codex Desktop 出现；切换设备 B 发送后只在 B 出现。
- [ ] 自动化测试覆盖配置迁移、设备增删改、设备级选择、草稿保护、连接事务和迟到回调隔离。
- [ ] HBuilderX Android 调试基座实测顶部弹窗、设备切换、返回设置页刷新和双设备发送链路。

## 非范围

- 不在首页设备弹窗中添加或编辑设备。
- 不允许同时订阅或并排显示多台设备。
- 不修改服务器 Key 管理后台。
- 不支持同一 Token 同时连接多个 Agent。
- 不跨手机或云端同步设备配置。
- 不重新设计对话列表、消息卡片和 Markdown 展示。

## 风险与约束

- uni-app 原生导航栏不能直接放置任意 Vue 组件。首页需要改用自定义导航栏，且必须处理 Android 状态栏安全区。
- 设备切换涉及多个异步数据源；必须以“设备 ID + 生命周期令牌”双重校验所有结果，不能只替换全局配置。
- Token 属于本地敏感配置，界面默认隐藏完整 Token，日志和错误信息禁止输出明文 Token。
